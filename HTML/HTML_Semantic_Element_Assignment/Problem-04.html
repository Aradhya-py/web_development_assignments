Technical Terminology

RAM (Random Access Memory)
High-speed volatile memory used by the system to hold data currently in active use.
SSD (Solid State Drive)
Flash-based storage offering ultra-fast read and write speeds compared to mechanical hard drives.
Refresh Rate
The frequency 240Hz at which the display updates with new images per second.
Warranty
Manufacturer guarantee covering hardware defects and repair services for a specified duration.
